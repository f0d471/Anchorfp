# fp 系列

标量 FP32 算术单元与定点窗口乘累加单元的开发记录。

五个标量单元（加减、乘、比较、转换、近似倒数）在 FTZ 语义下工作，
加、减、乘、比较与转换相对 IEEE-754 binary32 正确舍入；乘累加单元用一把定点尺子代替 FP32 累加器，
一块之内只舍入一次。

## 篇目

| | 章 | 覆盖内容 |
|---|---|---|
| 01 | [标量浮点单元的接口与契约](01-标量浮点单元的接口与契约.md) | 单元接口、分发层、延迟常数、操作码编码、三档契约、回归入口 |
| 02 | [FP32 乘法器的流水与舍入实现](02-FP32乘法器的流水与舍入实现.md) | 五步拆分、GRS 舍入、10 位带符号阶码、DAZ 与 FTZ、下溢判定时点、特殊值窄标志 |
| 03 | [FP32 加法器的三级流水实现](03-FP32加法器的三级流水实现.md) | 对阶、加减规格化、舍入组装、零的符号、窄信号重建与 hold |
| 04 | [FP32 比较器的三态编码与 NaN 语义](04-FP32比较器的三态编码与NaN语义.md) | 三态返回码、两族 NaN 方向、DAZ 规整 |
| 05 | [FP32 与整数转换单元实现](05-FP32与整数转换单元实现.md) | 两个方向的不对称、前导零与舍入、截断与饱和 |
| 06 | [FP32 倒数的查表与牛顿迭代实现](06-FP32倒数的查表与牛顿迭代实现.md) | 不替换除法的理由、牛顿迭代的写法、中点表、2 的幂特判 |

01 是骨架，02 到 06 各落地一个标量单元，07 与 08 是乘累加单元：07 是它的第一种结构，
08 把反馈环压到一拍，整体替换 07 的结构。每章正文写当前实现，被替换的旧实现与修复过程
记在该章的「遇到的问题」里。

按顺序阅读。只关心标量单元，读 01 到 06；只关心乘累加，读 01、02 之后读 07 与 08。
