# sfu 超越函数单元

对应 RTL：`exp_func.v`、`sincos_func.v`、`rsqrt_func.v`，正弦与余弦的固定包装
`sin_func.v`、`cos_func.v`，相位归约 `trig_phase_reduce.v`，查找表 `bram_lut_1024x32.v`，
延迟常数 `sfu_lat.vh`。查找表由 `gen_luts.py` 生成。

---

## 1. 职责

四个 FP32 标量函数：指数 `exp`、正弦 `sin`、余弦 `cos`、平方根倒数 `rsqrt`。
输入与输出都是 IEEE-754 binary32 位图。

四个单元采用同一种结构：把输入压缩到一个有界区间，用区间内的位置查 1024 项表，
再把压缩时保存的整数信息还原到结果的阶码或符号上。没有迭代，没有反馈环，
每个单元都是定长流水线。结果是近似值，不做正确舍入，不产生异常标志。

接口是单向的 `in_valid` 进、`out_valid` 出，没有反压。`flush` 作废所有在飞运算。

---

## 2. 单元

| 函数 | 单元 | 单元延迟 | 发起间隔 | 查找表 |
|---|---|:--:|:--:|---|
| exp | `exp_func` | 5 | 1 | `exp_lut.mem`，模块内例化 |
| sin | `sincos_func`，`is_cos = 0` | 2 | 1 | `sin_lut.mem`，模块外例化 |
| cos | `sincos_func`，`is_cos = 1` | 2 | 1 | 与 sin 共用 `sin_lut.mem` |
| rsqrt | `rsqrt_func` | 4 | 1 | `rsqrt_even_lut.mem`、`rsqrt_odd_lut.mem`，模块内例化 |

`sin_func` 与 `cos_func` 是把 `is_cos` 固定成常量的包装，供只需要其中一个函数的
调用方使用，延迟与 `sincos_func` 相同。

### 2.1 延迟的定义

`in_valid` 被采样的时钟沿记为 T，`out_valid` 拉高的时钟沿记为 T+N，N 即单元延迟。

测试台若从采样沿之后的第一个沿开始计数，量出来的值比 N 少 1。
比较两个延迟数之前，先确认两者的计数起点相同。

### 2.2 延迟常数

`sfu_lat.vh` 是四个延迟的唯一定义处：`EXP_FUNC_LAT`、`SIN_FUNC_LAT`、
`COS_FUNC_LAT`、`RSQRT_FUNC_LAT`。各值是仿真实测量，不由流水级数推算。
`tb_sfu_stream.v` 与 `tb_rsqrt_stream.v` 断言实测值等于宏值。

修改流水级数的流程：改 RTL，跑测试台取实测值，更新 `sfu_lat.vh`，重跑。
不得为了让判据通过而修改判据。

依据这些延迟搭建对齐流水的调用方，必须引用宏，不得另写数值。
模块头注释中的级划分只供阅读，与宏不一致时以宏为准。

### 2.3 发起间隔

四个单元的每一级都是寄存器，没有跨拍占用的共享资源，因此可以每拍发起一条。
`sincos_func` 由 `is_cos` 逐拍选择函数，SIN 与 COS 交错发起同样满足每拍一条。

同一个输入在同一拍需要同时得到 sin 与 cos 时，须例化两份 `sincos_func`。

### 2.4 端口

`exp_func` 与 `rsqrt_func`：

| 端口 | 方向 | 宽度 | 说明 |
|---|:--:|:--:|---|
| `clk` | in | 1 | 时钟 |
| `rst_n` | in | 1 | 同步低有效复位 |
| `in_valid` | in | 1 | 输入有效，单拍脉冲即可，`in_data` 不必保持 |
| `flush` | in | 1 | 作废所有在飞运算 |
| `in_data` | in | 32 | FP32 输入 |
| `out_valid` | out | 1 | 输出有效，单拍 |
| `out_data` | out | 32 | FP32 结果，与 `out_valid` 同拍有效 |

`sincos_func` 在此基础上增加：

| 端口 | 方向 | 宽度 | 说明 |
|---|:--:|:--:|---|
| `is_cos` | in | 1 | 0 为正弦，1 为余弦，与 `in_valid` 同拍给出 |
| `out_is_cos` | out | 1 | 与 `out_data` 同拍的函数标签 |
| `bram_addr` | out | 10 | 正弦表地址，组合输出 |
| `bram_dout` | in | 32 | 正弦表数据，同步读的输出 |

`bram_addr` 与 `bram_dout` 须接到一块以 `sin_lut.mem` 初始化的 `bram_lut_1024x32`。

## 3. 查找表

### 3.1 规格

`bram_lut_1024x32` 是四张表共用的结构：1024 项、32 位、同步读、无读使能，
综合推断为一块 BRAM36K。

1024 项是一块 BRAM36K（36,864 位）能容纳的最大二次幂深度，
下一档 2048 × 32 需要两块。表项存完整的 FP32 位图，还原时直接复用表项的符号、
阶码与尾数字段。

表地址由组合逻辑直连 BRAM 的地址口。BRAM 自带一级地址锁存，
在外部再寄存一次地址只会多付一拍延迟。

### 3.2 初值加载

表内容由 `$readmemh` 从 `.mem` 文件读入。这条语句同时服务综合与仿真。

`Memfile` 参数是裸文件名，综合器与仿真器各按自己的规则查找文件。
两侧找不到文件时都不会报错退出：

| 场景 | 找不到文件时的表现 |
|---|---|
| 综合 | 一条 CRITICAL WARNING，随后产出一块无初值的 ROM |
| 仿真 | 整块表读出 X，而 `X === X` 为真，硬件与硬件比较的判据会误判为通过 |

因此两侧各设检查：

| 侧 | 检查 | 抓什么 |
|---|---|---|
| 仿真 | `tb_rsqrt_stream.v` R5，`tb_sfu_stream.v` X3 | 结果中出现 X |
| 综合 | `check_sfu_luts.tcl` | 表缺失，项数、首末项或 SHA-256 与 manifest 不符 |
| 两侧 | `gen_luts.py --check` | 所有表与 manifest 与生成器输出逐字节一致 |

### 3.3 表的生成

四张表由 `gen_luts.py` 从公式确定性生成，表的取样口径以生成器为准：

| 表 | 表项 i 的值 | 取样点 |
|---|---|---|
| `exp_lut.mem` | `2^((i + 0.5) / 1024)` | 区间中点 |
| `sin_lut.mem` | `sin((π/2) · i / 1023)` | 闭区间，首项 0.0、末项 1.0 |
| `rsqrt_even_lut.mem` | `1 / sqrt(1 + i/1024)` | 区间左端点 |
| `rsqrt_odd_lut.mem` | `1 / sqrt(2 · (1 + i/1024))` | 区间左端点 |

表项先按 binary64 求值，再按 IEEE-754 就近舍入收成 FP32。
生成器同时写出两份 manifest：`sfu_lut_manifest.json` 供人和脚本读，
`sfu_lut_manifest.tcl` 供综合前检查读。两份都在 `--check` 的覆盖范围内。

各表的取样点与使用它的数据通路绑定，改其中一个必须同时改另一个，见第 4 节。

## 4. 数据通路

### 4.1 exp_func

令 `a = |x| · log2(e)`、`n = floor(a)`、`f = a - n`，则 `0 <= f < 1`，且

```text
x >= 0:  exp(x) = 2^n · 2^f
x <  0:  exp(x) = 2^(-a) = 2^(-n-1) · 2^(1-f)
```

`n` 加进结果的阶码字段，`2^f` 查表。

| 级 | 内容 |
|---|---|
| p0 | 拆包与分类，`|x|` 定点化为 Q8.20 |
| s1 | 乘常数 `log2(e)`（Q1.20），从积中切出 `n` 与 10 位表索引，完成负数映射与上下溢判定 |
| s1d | 与 BRAM 读并行，把旗标推到与表数据同拍 |
| s2 | 收表 |
| out | 把 `n` 加进表项阶码，按旗标选择特殊值 |

定点化需要双向移位：无偏阶码在 3 到 6 之间时左移，小于 3 时右移，
大于等于 7 时 `|x| >= 128`，结果必然上溢或下溢，直接走饱和分支。

常数 `Log2eQ120 = 0x171547 = round(log2(e) · 2^20)`。积的高 29 位是 Q9.20，
其中 `[27:20]` 为 `n`，`[19:10]` 为表索引。索引是纯截断，
误差落在区间 `[-1/1024, 0]` 内。

表按区间中点取样，截断误差被搬到 `[-0.5/1024, +0.5/1024]`。
负输入需要 `2^(1-f)`，而 `1-f` 所在区间的中点是 `((1023 - idx) + 0.5) / 1024`，
所以负数映射为 `(n, idx) → (-n-1, 1023-idx)`。取样点与镜像常数是绑定的一对，
只改其中一个会让误差区间偏出一整格。

中点取样的理论最大相对误差为 `ln2 / 2048 = 3.39e-4`。

极小正规数输入不经 DAZ（其阶码字段为 1），走正常通路，落在表的首末项上，
结果为 `2^(±0.5/1024)`，即 `0x3F800B18` 与 `0x3F7FE9D3`，而不是精确的 1.0。
这是中点取样的固有形态，误差在预算内。

上溢与下溢在阶码域判定：正输入 `n >= 128` 为上溢，负输入 `n >= 126` 为下溢。

### 4.2 sincos_func 与 trig_phase_reduce

`trig_phase_reduce` 是纯组合的相位归约，`sincos_func` 在其后加一级寄存与一级出口组装。

令 `P = |x| / (2π)`，`P` 的小数部分就是 `(|x| mod 2π) / (2π)`，即一个周期内的相位位置。
归约一次乘法完成，与角度大小无关。

| 步骤 | 内容 |
|---|---|
| 定点化 | `|x|` 转为 Q17.23，支持 `|x| < 2^17` |
| 乘法 | 乘常数 `1/(2π)`（Q0.32，`0x28BE60DC`），积为 Q17.55，丢弃整数部分 |
| 负角 | 对 55 位小数字段取二补数，低位即 `frac(-|x| / 2π)` |
| 余弦偏移 | 取小数高 12 位，余弦加 1024，即四分之一周期，12 位自然回绕 |
| 象限 | 高 2 位为象限，低 10 位为象限内位置；奇象限索引取 `1023 - 位置`，象限高位为结果符号 |

表只存四分之一周期。出口把表项的符号位换成结果符号，完成取负。

`cos(x) = sin(x + π/2)`，所以正弦与余弦的差别只在相位偏移，
`is_cos` 选择偏移，函数标签随 valid 链传到出口。

出口按以下顺序选择：

1. NaN、Inf、超出支持域：规范 qNaN `0x7FC00000`。
2. 仅正弦：定点化结果为零时输出保号的零。`sin(-0)` 走正常通路时索引与结果符号都落在 0，
   符号会丢失，因此需要这条出口。
3. 其余：`{结果符号, 表项[30:0]}`。

余弦没有零点出口：`x = 0` 时相位加 1024 后索引落在 1023，表按闭区间取样，
末项是精确的 1.0。denormal 与极小输入右移饱和归零，走同一个索引。

`|x| >= 2^17` 的有限输入超出 Q17.23 的整数位宽，`trig_phase_reduce` 置 `f_domain`，
出口返回 qNaN。相位没有最大值，把幅值饱和在边界上得到的是与输入无关的结果，
所以超出支持域时报告域错误，而不是返回一个看似合法的数。

### 4.3 rsqrt_func

对 `x = m · 2^e`，`m ∈ [1, 2)`：

```text
1/sqrt(x) = 1/sqrt(m) · 2^(-e/2)
```

`e` 为偶数时 `k = -(e/2)`；为奇数时 `k = -((e-1)/2)`，剩下的 `1/sqrt(2)` 因子
折进奇数表。奇数路取 `(e-1)/2` 与 `rsqrt_odd_lut.mem` 存 `1/sqrt(2m)` 一一对应。

| 级 | 内容 |
|---|---|
| p1 | 分类入寄存器：NaN、+Inf、负数、带符号零（含 DAZ） |
| p1 组合 | 奇偶判定与 `k` 的计算，尾数高 10 位直连两张表的地址口 |
| p2 | `k`、奇偶位与旗标入寄存器，与 BRAM 地址采样同拍 |
| p3 | 按奇偶位选择表输出并收表 |
| out | 偏置阶码 = 表项阶码字段 + `k`，按旗标选择特殊值 |

出口的偏置阶码取自表项自身的阶码字段，不是常数 127。`1/sqrt(m)` 对 `m ∈ [1, 2)`
落在 `(0.707, 1.0]`，除 `m = 1` 外表项阶码字段都是 126。

输入采用 DAZ：指数字段为 0 的位图按同符号零解释，正 denormal 出 `+Inf`，
负 denormal 出 `-Inf`。

## 5. 数值契约

| 输入 | exp | sin | cos | rsqrt |
|---|---|---|---|---|
| +0 / -0 | 1.0 | 保号的 0 | 1.0 | +Inf / -Inf |
| denormal | 按 0 处理 | 按同符号 0 处理 | 按 0 处理 | 按同符号 0 处理，即 +Inf / -Inf |
| 极小正规数 | `2^(±0.5/1024)` | 保号的 0 | 1.0 | 正常计算 |
| +Inf | +Inf | qNaN | qNaN | +0 |
| -Inf | +0 | qNaN | qNaN | qNaN |
| qNaN / sNaN | qNaN | qNaN | qNaN | qNaN |
| 负数 | 正常计算 | 正常计算 | 正常计算 | qNaN |
| 超出支持域 | 按上溢或下溢 | qNaN（`|x| >= 2^17`） | qNaN（`|x| >= 2^17`） | 不适用 |
| 上溢 | +Inf | 不适用 | 不适用 | +Inf |
| 下溢 | +0 | 不适用 | 不适用 | +0 |

表中 qNaN 一律为规范 qNaN `0x7FC00000`：不透传输入尾数，不保留符号位，sNaN 在此静默。

极小正规数单列一行，因为 DAZ 只作用于指数字段为 0 的位图，最小正规数的指数字段是 1，
走正常通路。

精度预算与实测：

| 函数 | 指标 | 预算 | 实测最大值 | 实测方法 |
|---|---|---|---|---|
| exp | 相对误差 | 4e-4 | 3.579e-4 | 9500 条固定激励，`verify_sfu.py` |
| sin / cos | 绝对误差 | 1.6e-3 | 1.501e-3 | 同上，`|x| < 2^17` |
| rsqrt | 相对误差 | 5e-4 | 4.881e-4 | 扫满两张表 2048 个正规点，`tb_rsqrt_stream.v` R11 |

预算是规格的一部分。改动后达不到预算时应当修改算子，而不是放宽预算。

契约表的消费者须同步更新：`verify_sfu.py` 的特殊值检查，以及调用方自己的板级测试与
头文件说明。

## 6. 流水实现约定

四个函数单元采用同一套写法：

| 部件 | 约定 |
|---|---|
| valid 链 | 单独一个 `always` 块，驱动 `out_valid` |
| `flush` | 只出现在 valid 链那一个块里 |
| 数据级 | 一律无条件推进，不做 valid 门控 |
| 出口寄存器 | 由末级 valid 门控 |

作废一条在飞运算等于让它的 valid 位消失，数据可以继续向下走，`out_valid` 为低时
`out_data` 没有意义。

数据寄存器不做 valid 门控。被延迟版 valid 门控的数据寄存器隐含两条要求：
输入保持至少两拍，且同时只有一条运算在飞。阻塞式调用方恰好满足这两条，
每拍发起一条的流水式调用方两条都不满足，结果会把相邻两条运算的字段配错。

同步读 BRAM 的读延迟用一级与读操作并行的寄存器对齐（`exp_func` 的 s1d、
`rsqrt_func` 的 p2），不依赖"晚一拍读上一级寄存器"。后者只在单条运算在飞时成立。

`flush` 的判据必须放在单元端口上。调用方若自带作废拦截（例如在应答路径上再清一次），
集成级测试台看不到单元内部 valid 链是否响应 `flush`。

## 7. 验证

| 层次 | 测试 | 覆盖 |
|---|---|---|
| 发起形态 | `tb_rsqrt_stream.v` | hold、pulse、每拍一条三种驱动逐位相同，延迟，flush，DAZ，2048 点误差预算，冻结参考 |
| 发起形态 | `tb_sfu_stream.v` | exp/sin/cos 的四种驱动逐位相同，延迟，零点，表末项，flush，超出支持域 |
| 共享流水 | `tb_sincos_shared.v` | SIN/COS 逐拍交错发起的顺序、标签、逐位结果与 flush |
| 逐位对拍 | `tb_sfu_golden.v` | 9500 条固定激励，输出与冻结的 `golden_ref.txt` 逐位比较 |
| 独立参考 | `verify_sfu.py` | 对同一批 RTL 输出按数学函数复核误差上限，并按第 5 节逐条查特殊值 |
| 表可复现 | `gen_luts.py --check` | 所有表与 manifest 逐字节等于生成器输出 |

`run_all.sh` 依次执行以上全部检查。

冻结参考与独立参考是两类判据，不能互相替代。冻结参考由 RTL 自身的输出冻结而来，
只回答"行为有没有变"，对产生它的那次改动没有判断力。有意改变行为时，
先由 `verify_sfu.py` 确认新行为合格，再重新冻结 `golden_ref.txt`。

固定激励 `vec.hex` 由 `gen_vec.py` 生成，覆盖特殊值、exp 上下溢阈值附近的逐步扫描、
三角函数四象限与支持域边界、rsqrt 的每个阶码，其余由固定种子的伪随机数补齐。

## 8. 设计取舍

| 项目 | 选择 | 依据 | 代价 |
|---|---|---|---|
| 实现方法 | 定义域压缩 + 查表 + 字段还原 | 延迟固定，无迭代，还原只涉及阶码与符号 | 精度受表规模限制 |
| 表规模 | 统一 1024 × 32 | 一块 BRAM36K 容纳的最大二次幂深度 | 精度在 1e-3 到 1e-4 量级 |
| 插值 | 不做 | 省掉一组乘加 | 误差由区间宽度决定 |
| 相位归约 | 相位分数法 | 一次乘法覆盖支持域内任意角度 | 支持域受定点位宽限制 |
| sin 与 cos | 一条流水两种发起 | 两者只差相位偏移，乘法共用 | 同一拍同时求两者须例化两份 |
| rsqrt 奇偶 | 两张表并行读 | 省掉开方与表后乘法，不增加读延迟 | 多一块 BRAM |
| exp 取样 | 区间中点 | 最大误差对半 | 极小正规数不再返回精确 1.0 |
| 特殊值 | 规范 qNaN、DAZ | 四个单元语义一致，与 FTZ 语义的 FP32 单元对同一位图解释相同 | 不透传 NaN 载荷 |
| 精度 | 近似，不做正确舍入 | 目标负载是推理与渲染，误差小于其量化台阶 | 不适用于需要正确舍入的场合 |

## 9. 编码约定

| 条目 | 做法 |
|---|---|
| 语言 | Verilog-2001，`wire` 与 `reg` 显式声明 |
| 复位 | 同步低有效，只复位 valid 链与出口寄存器 |
| 驱动 | 一个信号只由一个过程块驱动 |
| 位宽 | 显式位宽，负数索引映射先算进足宽中间量再截取 |
| 命名 | 常量 UpperCamelCase（`Log2eQ120`、`Inv2piQ032`），信号 lower_snake_case |
| 端口 | 不留未使用的端口 |
